# YUVI v0.1.1

YUVI now has a quieter Product WebUI and a dedicated application identity.
This Linux release brings together the desktop product work since v0.1.0:

- Linux desktop shell with tray controls and managed installer/portable packaging.
- New Product WebUI, including guided first-run setup and expanded zh-CN coverage.
- Companion and Subtitle desktop surfaces with visibility and placement controls.
- People, voice identity and Memory interfaces for reviewing and managing local context.
- Live2D ZIP import for user-provided models.
- Improved Local STT controls, status and on-demand lifecycle handling.
- New YUVI application and tray icons, independent of character artwork.

Linux x86-64 binaries target Debian 12 / glibc 2.36. The desktop requires the
system GTK/WebKitGTK 4.1 and AppIndicator runtime libraries. Provider credentials
and some model/runtime prerequisites still require setup. Voice matching and
speaker diarization remain experimental; they are not authentication features.
Live2D Cubism Core and proprietary character assets are not included.
